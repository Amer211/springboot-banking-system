# springboot-banking-system
A RESTful banking API built with Spring Boot for managing bank accounts and transactions
A monolithic banking application built with Java and Spring Boot.
The project provides RESTful APIs for managing bank accounts, transactions, and users within a single backend application.

The application is designed to practice core backend development concepts such as:

Spring Boot architecture
REST API development
Database integration
Service and repository layers
Validation and exception handling
Authentication and authorization
Features
Create and manage bank accounts
Deposit and withdraw money
Transfer funds between accounts
Transaction history
User management
RESTful APIs
Input validation
Global exception handling
MySQL database integration
Technologies Used
Java
Spring Boot
Spring Web
Spring Data JPA
Spring Security
MySQL
Maven
Lombok
